# DOC-32 派生值可验 / 预算收口 / route_by 进 state

> 2026-11-19 · 承接 DOC-31（意图判据改成代价分档）
> 触发：全量 27 条里 7 条带"有未溯源数字"（共 8 个），1 条（A3）烧满 12 步、结论为空。

## 一、要解决的三件事，性质各不相同

| 现象 | 真实性质 | 之前怎么处理的 |
|---|---|---|
| 7 条用例共 8 个数字标灰 | **不是模型编造**，是它自己算出来的比值/差值，没有字段可指 | 标灰放行，永远不进任何统计 |
| `A3` 烧满 12 步、`final_head` 为空 | **到点没交卷**，不是"查得不够" | 记为 `budget_exhausted`，但结论只能是空白 |
| `route_by` 只进 trace | **记了没人拿得到**：`run_eval` 传 `trace_run=False`，评测链不落 `runs/` | 文档里写着"用来算误伤率"，实际算不出来 |

**三件事的共同点**：它们在报表上都表现为"没有数据"，而不是"错了"。**没有数据的错最难修，因为你连它存在都看不见。**

## 二、一手依据

- **引用单位**：Anthropic 的 Citations 文档把引用定义成**原文片段**（`cited_text` + `start/end index`），位置由模型给、原文由 API 填。本项目把"引用"从文本解析搬到 `ref` 字段，逻辑同源：**要么指到一个能核对的字段，要么给一个能重算的算式。** 两者之外才是"编的"。
- **停止语义**：Anthropic Messages API 把 `end_turn` 与 `max_tokens` 分成两个值——**一个是被完成，一个是被截断**。项目里 `enough` / `budget_exhausted` 的拆分就来自这条（`nodes.py:808` 起的注释）。这次补的是：**被截断时也要有东西可交**。
- **可观测性**：一个指标如果拿不到，就等于不存在。`route_by` 从 trace 挪进 state，不是因为 trace 不好，而是**评测链不读 trace**。

## 三、改法（三处，都在 `app/graph/`）

### ① 派生值可验（`nodes.py`）

新增三个纯函数 + 一处接入：

- `_safe_arith(expr)`：只算 `+ - * /` 和括号，**AST 白名单，绝不用 `eval`**。expr 来自模型输出，在这里求值等于让它在这台机器上执行代码。
- `_derive_expr(c, text)`：先取显式 `expr` 字段，再取 `text` 里形如 `（=20/27）` 的括号。**两种都认是故意的**：prompt 改了模型不会立刻照做，而 text 里的算式它一直在写（原 prompt 第 110 行本来就这么要求，只是没人去核）。
- `_verify_derived(c, text, v, unit)`：重算并比对，百分比按 `%` 换算。

接入点在 `_verify_claims` 的 `if not ref:` 分支：

```
有算式且算得对  → derived_ok（成立，不标灰）
有算式但算错    → derived_bad + failure: derived_wrong（判失败）
没算式          → 仍然 unsourced（标灰，和以前一样）
```

**边界必须这么切**，否则这条路会变成洗白通道：一律放行 → 假算式能救任意数字；一律判死 → 模型学会删算式，数字留在结论里从"可查"退化成"查不到"。

### ② 预算收口（`nodes.py` 的 `_plan_notes`）

`left = MAX_STEPS - used`，当 `left <= 2` 时追加一条 `[收口提醒]`：把已查到的写成结论、把没查到的明确列出来、不要在最后一次调用上开新方向。

**为什么不把 `MAX_STEPS` 从 12 调大**：那只是把同一个失败点往后挪几分钟。预算的意义是"到点必须交卷"，不是"多给几次机会"。

### ③ `route_by` 进 state（`state.py` + `nodes.py`）

- `state.py`：`State.route_by: str`、`RESET_EACH_TURN["route_by"] = ""`、`STATE_VER` **2 → 3**。
- `nodes.understand`：return 里加 `"route_by": route_by`（原来只 `trace.emit`）。
- `eval/run_eval.py`：结果 dict 加 `route_by`，汇总加一行 `派生值重算 N 成 / M 败`。

**为什么进 `RESET_EACH_TURN` 而不是常驻**：它是本轮的路由结果。不清的话，第 1 轮被规则命中的用例，第 2 轮明明走模型，报告上还写着 `rule:xxx`——误伤率会凭空多出一条。

## 六、未决
